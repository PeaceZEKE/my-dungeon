# 정투영 참고도 → 모델 실루엣 맞추기

`ortho.py` (numpy · Pillow 만)

1. **참고도 검사** — `python3 viewers/fit/ortho.py check <4면도.png> fsbt|ofbt`
   네 그림 높이 편차 · 바닥선 · 정면/후면/위 좌우 대칭 · 정면 폭 = 위 폭 · 측면 깊이 = 위 깊이. `ok:false` 면 다시 뽑는다
   (코덱스가 '정면'이라 해도 3/4 원근으로 그린 그림은 여기서 걸린다 — 기사 투구 첫 4면도·어깨 첫 두 장이 그랬다).
   순서 `fsbt` = 정면·측면(앞이 왼쪽)·후면·위(앞이 아래) · `ofbt` = 바깥 측면(앞이 오른쪽)·정면·후면·위.
2. **비주얼 헐 로프트** — `ortho.loft(path, order, levels, H)` 가 높이마다 정면 윤곽의 폭 · 측면 윤곽의 앞뒤 끝 · 위 윤곽을
   교집합해 단면을 구하고 중심에서 32방향 반지름으로 바꾼 링 `[y, cx, cz, r×32]` 을 돌려준다(앞 = −z). 정면·측면 실루엣이 구조상 맞는다.
   게임 코드는 이 링 표(`HELM_RINGS`·`PAULD_RINGS`)를 그대로 들고 같은 표면 위에 금 띠·눈 틈 같은 세부를 얹는다.
3. **검증은 면적 겹침(IoU)이 아니라 윤곽 거리** — `ortho.contour_dist(ref, ours)` (높이를 맞춘 뒤 평균·최대 거리, 높이 대비 %).
   IoU 0.9 라도 윤곽이 몇 % 어긋나면 눈에는 다르게 보인다.

함정: 렌더 실루엣을 찍을 때 카메라 중심이 물체 가운데가 아니면 위가 잘려 '모델이 납작하다'로 오판한다(어깨에서 겪었다).
